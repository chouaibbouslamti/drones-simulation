1. Description du Projet
Une entreprise de livraison souhaite utiliser une flotte de drones pour réaliser ses livraisons à
domicile. La carte de la ville est représentée par une forme rectangulaire et elle contient des
obstacles. Pour déplacer les drones d'un point à un autre sur cette carte, les ingénieurs de
l'entreprise planifient un chemin à suivre par chaque drone. Chaque jour, les ingénieurs
envoient aux drones des chemins codifiés pour effectuer leurs livraisons.

1.1 Représentation de la Position d'un Drone
La position actuelle d'un drone est représentée par des coordonnées x et y de la carte ainsi
qu'une lettre pour indiquer son orientation :



La position 0 0 N indique que le drone est situé en haut à gauche de la carte et orienté vers
le nord.
Nous considérons qu'un drone est orienté vers le nord lorsqu'il se déplace sur le plateau de
(x,y) à (x,y+1).

1.2 Codification des Mouvements
Le chemin envoyé pour chaque drone est codifié sous la forme d'une chaîne de caractères, où
chaque caractère représente le mouvement à effectuer par le drone :
Caractère
L
R
M
B

Action
Tourner de 90° sur place à gauche
Tourner de 90° sur place à droite
Avancer d'une case dans la même direction
Reculer d'une case dans la même direction

Position finale du drone : 1 4 S

1.4 Comportement du Drone face aux Obstacles






Le drone ne traverse pas les obstacles et ne les contourne pas. Il exécute seulement la
chaîne des commandes.
Si la case suivante vers laquelle il doit avancer (commande M) ou reculer (commande B) est
occupée par un obstacle, alors il reste sur place et continue à exécuter les commandes
suivantes.
L'exécution continue jusqu'à ce qu'une commande lui permet de se déplacer vers une case
libre.
Comportement à la sortie de la carte : Si un drone tente de sortir de la carte, il continue son
chemin dans la direction opposée (wrapping).

1.5 Objectif du Projet
Programmer en Java un simulateur des déplacements d'un ensemble de drones sur un
plateau avec des obstacles. Vous allez développer 3 versions du simulateur de vol :
Version 1 : Séquentielle

Dans cette version, les drones se déplacent vers leurs destinations l'un après l'autre sans
aucune synchronisation. Les positions des drones et leurs commandes sont fournis dans un
fichier texte.
Version 2 : Concurrente

Dans cette version, les drones se déplacent vers leurs destinations de façon concurrente
(simultanément). Les positions des drones et leurs commandes sont fournis dans un fichier
texte. Chaque drone exécute ses mouvements dans un Thread séparé.
Version 3 : Communicante

Les drones se déplacent de façon concurrente et reçoivent leur position initiale et les
commandes (chaîne de caractères) depuis le réseau via un programme client (station de
commande). Dans cette version, vous devez également développer le programme client qui
envoie les informations au programme serveur (simulateur) en utilisant les Sockets Java.





Utiliser les Sockets TCP de Java (java.net.Socket, java.net.ServerSocket)
Le simulateur fonctionne en mode serveur (écoute sur un port)
Le programme client envoie les informations au serveur

4.2.2 Protocole de Communication

Phase 1 : Démarrage du Serveur
1. Lancer le simulateur avec l'option "serveur"
2. Le serveur écoute sur un port (ex: 5000)
3. Le serveur attend les informations du client

Phase 2 : Connexion du Client
1. Lancer le client
2. Le client se connecte au serveur (localhost:5000)
3. Le client envoie :
- Taille de la carte (width, height)
- Nombre de drones
- Pour chaque drone : position (x, y), orientation (N/S/E/W), commandes

Phase 3 : Exécution de la Simulation
1. Le serveur reçoit les informations
2. Le serveur valide les données
3. Le serveur démarre la simulation (threads concurrents)
4. Le serveur affiche la simulation
5. Le serveur envoie au client les positions et orientations finales

Phase 4 : Affichage côté Client
1. Le client reçoit les positions finales
2. Le client affiche la carte avec les positions finales
3. Optionnel : afficher en continu les mouvements (streaming)

5.1 Gestion des Obstacles
public class SimulatorMap {
private char[][] grid;
private int width;
private int height;
private static final char OBSTACLE = '#';
private static final char EMPTY = '.';
public boolean isBlocked(int x, int y) {
if (x < 0 || x >= width || y < 0 || y >= height) {
return false; // Wrapping
}
return grid[y][x] == OBSTACLE;
}
public int wrapCoordinate(int coord, int max) {
return ((coord % max) + max) % max;
}
}

5.2 Classe Drone
public class Drone {
private int x, y;
private char orientation; // N, S, E, W
private String commands;
public void executeCommand(char cmd, SimulatorMap map) {
switch (cmd) {
case 'L':
turnLeft();
break;
case 'R':
turnRight();
break;
case 'M':
moveForward(map);
break;
case 'B':
moveBackward(map);
break;
}
}
private void moveForward(SimulatorMap map) {
int newX = x, newY = y;
switch (orientation) {
case 'N': newY++; break;
case 'S': newY--; break;

14

case 'E': newX++; break;
case 'W': newX--; break;
}
// Wrapping
newX = map.wrapCoordinate(newX, map.getWidth());
newY = map.wrapCoordinate(newY, map.getHeight());
if (!map.isBlocked(newX, newY)) {
x = newX;
y = newY;
}
}
}
